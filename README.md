# SmartAgro 🌾
> **Empowering Agriculture through Real-Time Analytics & Artificial Intelligence.**

[![Flutter](https://img.shields.io/badge/Flutter-02569B?style=for-the-badge&logo=flutter&logoColor=white)](https://flutter.dev)
[![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=for-the-badge&logo=firebase&logoColor=black)](https://firebase.google.com)
[![Google Gemini](https://img.shields.io/badge/Google_Gemini-8E75C2?style=for-the-badge&logo=google&logoColor=white)](https://deepmind.google/technologies/gemini/)

SmartAgro is a comprehensive, multi-persona agricultural ecosystem designed to bridge the gap between farmers and platform owners. By leveraging **Google Gemini AI** for crop diagnostics and **Firestore** for real-time strategic reporting, SmartAgro transforms traditional farming into a data-driven, high-yield operation.

---

## 🏗️ Architecture & Core Personas

### 🧑‍🌾 The Farmer Persona
Designed for accessibility and advanced expert support.
- **AI Plant Doctor**: Instant crop disease diagnosis using multi-modal Gemini Flash AI.
- **Smart Shop**: Localized product discovery with Aadhar-verified secure checkout.
- **Advisory Hub**: Voice-enabled product search and professional dosage calculators.
- **Live Tracking**: Real-time order lifecycle monitoring with localized notifications.

### 👔 The Owner Persona
A strategic command center for regional agricultural governance.
- **Live Revenue Dashboard**: Real-time sales metrics and profit estimation.
- **Strategic Reports**: 7-day revenue trends, busy-hour heatmaps, and dead-stock detection.
- **Inventory Control**: Bulk stock ingestion via CSV and predictive demand analysis.
- **Farmer Management**: Comprehensive portfolio oversight with aadhar-back identity auditing.

---

## 🚀 Key Features

### 🧠 AI Plant Doctor (Powered by Gemini)
Submit images of diseased crops to receive:
- Precise disease identification.
- Severity rating (Low/High).
- Organic & Chemical treatment recommendations.

### 📊 Real-Time Strategy Hub
- **Sales Analytics**: 24-hour bar charts and 7-day line graphs.
- **Customer Insights**: Retention analytics and dormancy triggers.
- **Inventory Health**: Automated asset valuation and restock priority alerts.

### 🌐 Localization & Accessibility
- **Full Bilingual Support**: Toggle seamlessly between English and Tamil.
- **Voice Search**: Hands-free navigation for better accessibility in the field.

- **Frontend**: Flutter (Mobile)

## 📦 Getting Started

### Prerequisites
- Flutter SDK (Latest Stable)
- Java 11+ / CocoaPods (for iOS)
- A Firebase Project with Firestore enabled

### Installation
1.  **Clone the Repository**
    ```bash
    git clone https://github.com/Yahyaimthiyas/SmartAgro.git
    cd SmartAgro/mobile
    ```

2.  **Install Dependencies**
    ```bash
    flutter pub get
    ```

3.  **Configure Firebase**
    - Place your `google-services.json` in `android/app/`.
    - Place your `GoogleService-Info.plist` in `ios/Runner/`.

4.  **Run the Application**
    ```bash
    flutter run
    ```
